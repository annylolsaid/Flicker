O tema do site é um festival de música com estilo alternativo/rock, usando cores marcantes e elementos visuais artísticos.

O Flexbox foi utilizado em 4 partes principais:

Body
Header
Menu de navegação (nav)
Main/containers das seções

Os breakpoints foram pensados para desktop, usando unidades responsivas (vh, %, flex) para adaptar o layout a diferentes tamanhos de tela.
